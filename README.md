# Idola Laundry

Idola Laundry adalah aplikasi operasional untuk membantu usaha laundry mengelola pesanan, pelanggan, layanan, kas, karyawan, dan laporan harian dalam satu tempat.

Repositori ini berisi pengembangan aplikasi internal Idola Laundry. Informasi teknis, kredensial, dan konfigurasi produksi tidak dipublikasikan di README ini.

## Fitur Utama

- Manajemen pesanan laundry kiloan dan satuan.
- Data pelanggan dan riwayat pesanan.
- Master layanan dan harga.
- Pencatatan pembayaran tunai, transfer, dan metode non-tunai lain.
- Buku kas dengan pemisahan pemasukan dan pengeluaran.
- Pengelolaan karyawan, absensi, shift, payroll, dan request karyawan.
- Laporan operasional untuk memantau transaksi dan performa harian.
- Dukungan mode online serta fallback terbatas ketika koneksi belum tersedia.

## Status

Aplikasi sedang dikembangkan dan diuji untuk penggunaan operasional Idola Laundry. Beberapa fitur dapat berubah mengikuti kebutuhan toko dan hasil pengujian lapangan.
