# Tutorial Karyawan Idola One

Buka `index.html` untuk membaca tutorial bergambar. Tombol **Cetak / Simpan PDF** dapat digunakan dari browser.

Screenshot di folder `images/` dibuat dari renderer Flutter berukuran 390 × 844 dengan data preview, bukan data pelanggan produksi.

Untuk membuat ulang screenshot setelah UI berubah:

```powershell
cd laundry_app_flutter
flutter test tool/tutorial_capture_test.dart --update-goldens
```
